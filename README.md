- **Course Title:** Web Programming Laboratory

## 📚 Project Overview

This repository contains laboratory assignments, practical exercises, and mini projects completed for the **Web Programming Laboratory** course. It covers the fundamental concepts of modern web development, including front-end design, client-side scripting, server-side programming, database integration, and form handling. The repository is designed to strengthen practical web development skills through hands-on implementation. :contentReference[oaicite:0]{index=0}

## 📁 Repository Structure

### 1. HTML & CSS Labs
A collection of programs demonstrating the fundamentals of web design:
- HTML5 document structure
- Forms, tables, lists, and semantic elements
- CSS styling, layouts, Flexbox, and responsive design

### 2. JavaScript Programs
Interactive web applications and client-side scripting:
- DOM manipulation
- Events and event handling
- Form validation
- Arrays, functions, loops, and ES6 features

### 3. Backend Development
Server-side programming examples covering:
- PHP fundamentals
- Form processing
- Session and cookie management
- File handling

### 4. Database Integration
Database-driven web applications including:
- MySQL database connectivity
- CRUD (Create, Read, Update, Delete) operations
- Authentication and data management

## 🛠️ Key Concepts Covered

- **HTML5:** Semantic web page structure and forms
- **CSS3:** Responsive layouts and modern styling techniques
- **JavaScript:** Dynamic and interactive web functionality
- **PHP:** Server-side scripting and application logic
- **MySQL:** Database design and CRUD operations
- **Form Validation:** Client-side and server-side validation techniques

## 🚀 Getting Started

### Prerequisites

- A modern web browser (Chrome, Firefox, Edge, etc.)
- Visual Studio Code or any preferred code editor
- XAMPP/WAMP/Laragon for running PHP and MySQL applications

### How to Run

1. Clone this repository.
2. Open the project folder in your preferred code editor.
3. Run HTML files directly in your browser.
4. For PHP projects, place the folder inside your local server directory (e.g., `htdocs` for XAMPP).
5. Start **Apache** and **MySQL** from your local server.
6. Open the project in your browser using `http://localhost/your-project-folder/`.
